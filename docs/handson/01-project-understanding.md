# 01. 프로젝트 이해 (세션 A)

본 실습에서는 Copilot 세션에서 자연어로 질문하여 문의 조회 샘플의 주요 기능과 코드 구조를 이해합니다.
답변의 코드 근거를 확인하며, 미처리·완료 문의를 구분하는 기준을 파악합니다.

## 프로젝트 질문하기

GitHub 우측 상단의 Copilot 아이콘을 클릭한 뒤 [New Session](https://github.com/copilot) 메뉴를 클릭합니다.
실습 준비 단계에서 fork한 본인의 실습 저장소를 연결합니다.
세션을 시작하기 전에 `Environment → Cloud`를 선택하고 조직이 승인한 환경인지 확인합니다.
설명만 요청하는 경우에도 확인하며, `Actions` 환경은 선택하지 않습니다.
승인된 Cloud 환경을 선택할 수 없으면 세션을 시작하지 않고 준비 담당자에게 확인합니다.

다음과 같이 Copilot 세션에서 자연어로 요청하여 프로젝트 내용을 파악합니다.
이 단계는 설명만 요청하며 코드 변경이나 실행 작업은 시작하지 않습니다.

### 1. 질문하기

```text
조직/저장소를 처음 보는 업무 담당자야.
이 프로젝트는 누가 사용하고 어떤 문제를 해결하는지 쉽게 설명해줘.
문의 조회의 주요 기능과 미처리·완료를 구분하는 기준은 무엇이야?
현재 화면의 건수에 어떤 상태가 포함되는지도 확인해줘.
설명의 근거가 되는 코드·문서·테스트의 GitHub 링크를 알려주고,
실제 구현과 문서 설명이 다른 부분이나 확인하지 못한 내용은 구분해줘.
지금은 설명만 하고 코드 변경이나 실행 작업은 시작하지 마.
```

### 2. 근거 확인하기

답변에 제시된 GitHub 파일 링크를 브라우저에서 열어 원문과 대조합니다.
본인의 실습 저장소와 브랜치를 근거로 답했는지, 미처리·완료 판단 기준이 코드와 일치하는지 확인합니다.

### 3. 추가 질문하기

이번에는 다음과 같이 추가 질의를 해봅니다.

```text
방금 설명한 내용 중 코드로 확인한 기능 세 가지를 정리해줘.
서버나 DB를 실제로 사용하는 부분과 교육용 예시 코드를 구분해줘.
아직 확인하지 못한 사항 한 가지와 추가로 확인할 위치도 알려줘.
새 검사를 실행하지 말고 현재 저장소의 근거만 사용해줘.
```

답변에서 현재 기능 세 가지, 미처리 판단 기준과 확인하지 못한 사항 한 가지가 설명됐는지 확인합니다.

이외에도 프로젝트와 관련하여 궁금한 내용들을 자유롭게 질문해 봅니다. Actions 실행은 요청하지 않습니다.

<details>
<summary>추가 설명: 설명 요청과 구현 요청</summary>

자연어 기반 실습은 모두 Copilot 세션에서 진행하며, 요청할 작업의 범위를 구분합니다.
이번 단계는 구현을 맡기는 것이 아니라 설명을 요청해 프로젝트를 이해하는 단계입니다.

| 구분 | 설명 요청 | 구현 요청 |
|------|--------------|------------|
| 용도 | 프로젝트 질문, 설명, Issue 초안 작성, PR·보안 결과 해석 | 코드·테스트 수정, 테스트 실행, PR 생성·보완 |
| 요청 예시 | “미처리 건수는 어떻게 계산하나요? 코드 근거를 알려줘.” | “이 Issue의 완료 조건에 맞게 미처리 건수 표시를 구현해줘.” |
| 확인할 결과 | 답변의 근거, 초안, 검수 의견 | 실제 변경 파일·커밋, 테스트 결과, PR |
| 이번 실습의 사용 범위 | Copilot 세션에서 질문·초안·검수만 요청 | Copilot 세션에서 실행 환경이 승인된 Cloud 샌드박스인지 확인한 뒤 구현 요청 |

Copilot 세션에서도 설명 요청과 코드 변경·실행 요청을 구분해 명시합니다.
Issue·댓글 게시 가능 여부는 도구·권한에 따라 확인하며, 게시 요청을 구현 요청과 구분합니다.
코드 변경·테스트 실행을 요청하기 전에는 승인된 Cloud 환경인지 확인합니다.
답변만으로 실제 실행을, 에이전트 작업 완료만으로 요구사항 충족이나 보안 경고 해소를 판단하지 않습니다.
