## 새로운 기능

상태와 기간을 함께 적용해 문의를 조회할 수 있습니다.

## 주의·업그레이드 안내

기간이 거꾸로 입력되면 안내하고 조회를 막습니다.

업그레이드 시 추가 설정은 없습니다.
