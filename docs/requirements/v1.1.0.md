### 요청 내용

문의 목록에서 **상태와 조회 기간을 함께 적용**해 원하는 문의를 찾고 싶습니다.
기존 전체 조회는 유지합니다.

이 요청은 가상 서비스의 교육용 샘플입니다. 수강자가 직접 개발하는 실습 과제가 아닙니다.

### 완료 조건

- [x] 상태와 조회 기간을 함께 적용한다.
- [x] 잘못된 기간 입력은 안내하고 조회하지 않는다.
- [x] 결과가 없으면 그 사실을 안내한다.

### 연결된 변경과 확인 결과

- `feature/status`: 상태 검색
- `feature/date`: 기간 검색·예외 안내
- 기능 PR → 배포 준비 PR → 릴리스 반영 PR → 최종 릴리스 공지로 연결합니다.

확인한 것과 남은 항목은 댓글·PR·테스트 결과·배포 기록을 기준으로 이어 봅니다.
